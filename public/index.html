Angular Material M3 CSS Theme Generator For NDE

Use this tool to create a custom color theme for Primo NDE. The colors that are generated are based on the colors you choose below. Select a primary color and optionally provide custom secondary, tertiary, or neutral colors. Any colors that are not customized will be generated automatically based on the colors you do choose.

Once the theme has been generated, place the downloaded customized-theme.css file in the [Your-View-Code]/assets/css folder of your Primo NDE customization package.

Then add the following line to your package's custom.css file: 

@import url("customized-theme.css");

After deploying the updated customization package, clear or reset your browser cache before viewing NDE. The previous theme may remain visible until the cached CSS is refreshed.
